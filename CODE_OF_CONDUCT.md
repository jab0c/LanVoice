# Code of Conduct

Hi! I’m a junior developer and I want this to be a friendly, low‑stress project. Please help keep the vibe kind and respectful.

## Be Kind

- Be respectful and patient.
- Assume good intent.
- Give constructive feedback.
- No harassment, hate speech, or personal attacks.

## Be Helpful

- Keep discussions focused on the project.
- Share ideas with empathy.
- If you’re unsure, ask.

## Reporting

If something feels wrong, please open a GitHub issue and I will take a look. I’m learning, so I appreciate clear, kind reports.

Thanks for helping make this a welcoming space.
