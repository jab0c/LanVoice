# Contributing

Thank you for checking out LAN Voice Lite. I’m a junior developer, so kindness and clear feedback go a long way.

## Before You Start

- Keep changes small and focused.
- Performance matters. Please avoid heavy dependencies or anything that adds latency.
- Cross‑platform behavior matters (macOS + Windows). If possible, note which OS you tested.

## How to Contribute

- Open an issue to discuss a bug or idea.
- Fork the repo and create a feature branch.
- Submit a PR with a short, clear description.
- If you touch audio or networking, include notes about latency impact.

## Testing

If you can, run:

```bash
python3 lan_voice_lite.py
```

and mention your OS and device setup in the PR.

Thanks again for helping.
